ZOMBIES / CONTAINMENT GATE COORDINATE WORKSHEET
================================================

Use this file to collect the real floor positions for gate placement.

HOW TO CAPTURE
--------------
1. Load the relevant map in Zombies / Containment.
2. Aim at the floor directly beneath the centre of the doorway or choke point.
3. Press P.
4. Copy the value labelled "Ground" from the on-screen notification.
   Do NOT use the copied "Spawn" value for yHint: Spawn Y is 18 units higher
   because it is the player's eye position.
5. Paste the Ground value below, add the direction a barrier should face, and
   describe the opening it must block.

For wider or irregular doorways, capture LEFT EDGE, CENTRE, and RIGHT EDGE
floor coordinates while standing on the locked/start-area side. A screenshot
with the three locations is also useful.

RETURN FORMAT
-------------
You can send this file back filled in, or paste entries in this exact shape:

  Map: nuke
  Gate: service-link
  Ground centre: { x: 0.00, y: 0.00, z: 0.00 }
  Ground left edge: { x: 0.00, y: 0.00, z: 0.00 }
  Ground right edge: { x: 0.00, y: 0.00, z: 0.00 }
  Barrier faces: north/south OR east/west
  Notes: Blocks [area] from [start area].
