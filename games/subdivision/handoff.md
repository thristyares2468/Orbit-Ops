## Important Files

- `index.html`: very large client/game/UI file. Contains rendering, menu hub, inventory, marketplace, case editor UI, case roll animation, MVP presentation, HUD, audio, input, mobile controls, GLB previews, and gameplay client logic.
- `server.js`: WebSocket game server. Owns rooms, auth-gated packets, combat authority, round state, scoring, utility, healthshot state, inventory/case/market/trade socket handlers, friends/parties, admin flows, XP/challenges, and persistence calls.
- `db.js`: Postgres data layer. Owns accounts/sessions/devices, stats, news, inventory/loadouts, cases/openings, custom cases, Mowbucks, marketplace listings, trades, friends, bans, violations, and chat logs.
- `skins.js`: curated skin/case catalog, rarity names, case sanitizer, secure case roll helpers, and merge point for generated imported skins.
- `tradeups.js`: pure server-side Trade Up rarity, collection-pool, normalized-float, wear, and secure outcome-selection rules.
- `skins_imported.js`: generated catalog rows from imported weapon skin metadata. Do not hand-edit item rows; regenerate through the importer/asset pipeline.
- `core.js`: shared authoritative constants and snapshot helpers loaded by Node and the browser.
- `maps.js`: shared admin-only map catalog plus authored CT/T spawn points and yaw.
- `mapCollision.js`: server-side GLB collision/ground/LOS geometry validation.
- `auth.js`, `mailer.js`, `fingerprint.js`, `antiflood.js`, `bans.js`, `admin.js`: auth, Brevo/Resend/SMTP delivery, device identity, flood/rate limiting, ban enforcement, and HTTP admin panel.
- `legal.html`: lightweight static legal/privacy page. It intentionally does not load the full game renderer.
- `scripts/build-skin-glbs.js`: embeds skin PNGs into source GLBs for shipped skin models.
- `scripts/import-goldsrc-map.js`: converts supplied GoldSrc BSP v30 maps into lit, textured GLBs, corrects BSP face winding, resolves explicit WAD3 archives, applies Valve `materials.txt` footstep tags, generates a fallback only for genuinely unresolved textures, and exports authored spawns.
- `scripts/export-map-texture-catalog.js`: exports the exact textures embedded in the four shipped imported-map GLBs and builds a paged labeled contact sheet.
- `test/*.js`: mostly static regression tests that lock down high-risk contracts in the large single-file client/server code.

Wear-mask textures use mipmaps/anisotropy and a fixed broad shader feather; do not restore the screen-derivative-driven `fwidth` boundary that visibly changed while first-person weapons moved.
